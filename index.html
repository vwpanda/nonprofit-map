Connect your shared data source (Google Drive)

  1. ⬇ Download the Excel template (.xlsx) — exact headers plus sample rows. Category, County, and Active are dropdown cells. Put each organization's street address in Addresses; for a nonprofit with several sites, separate the addresses with a semicolon (;). The map locates each address automatically. (To edit dropdown options, unhide the "Lists" tab.)
  2. Upload it to Google Drive, then right-click it → Open with → Google Sheets (this turns it into a live, editable Sheet).
  3. Click Share → under General access choose "Anyone with the link → Viewer" (and give your employees Editor access so everyone works from one database).
  4. Copy the sheet's normal link from the Share dialog (or the address bar — it looks like …/spreadsheets/d/<id>/edit), paste it below, and click Connect.
Tip: the normal share link works even when you open this file by double-clicking it. (A "Publish to web → CSV" link also works, but only when this page is hosted on a web address.)
